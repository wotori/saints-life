# Проверка прототипа

Дата: 4 ноября 2026 года.

## Результаты

- `npm run check`: ESLint, TypeScript и 8 предметных тестов прошли.
- `npm run build`: production-сборка Next.js прошла.
- `npm run test:e2e`: 8 сценариев прошли, 4 сценария в desktop Chrome и 4 в мобильном размере iPhone 13 с движком Chromium. Это эмуляция размеров и взаимодействия, не тест настоящего iOS/Safari.
- Визуально просмотрены главная и читалка, отдельно мобильные первый экран главной и календарь. Скриншоты лежат в `test-results/`.
- Проверены реальные переходы и HTTP 404, поиск Дмитрий/Димитрий, 68 результатов, пагинация, фильтр традиции, отсутствие результата, сброс значений формы.
- В читалке проверены источник, смена самостоятельных произведений, внешние ссылки, размер шрифта, тёмный фон и сохранение закладки после перезагрузки.
- В календаре проверены 8 ноября 2026 года, переход к 26 октября старого стиля без смены физического дня, старообрядческий фильтр, восстановление URL после перезагрузки и переход на память Аввакума 27 апреля.
- Предметные тесты проверяют високосный 2100 год, изменяющуюся разницу календарей, границы годов, связи источников и данных, сохранение тёзок и исключение переходящих памятей без правил.
- В архиве проверены существование и совпадение SHA-256 всех 8 успешно скачанных оригиналов. Для PDF проверен заголовок формата. Постраничная сверка литературы, изданий и OCR ещё не выполнена.

Браузерный прогон использует отдельную production-сборку на 3101 и два параллельных процесса. Он не зависит от hot reload и не переиспользует рабочий dev-сервер.

## Границы

На сайте 68 исходных записей о Димитриях, а не проверенный полный список всех уникальных святых всех традиций. 7 локальных текстов являются краткими редакционными изложениями. Полные исторические тексты пока открываются у издателей. Свидетельства по другим согласиям и вычисляемые переходящие памяти требуют пополнения.

Из 21 адреса архива удалось скачать 8 полных оригиналов. У 13 остальных сохранены URL, статус ошибки, а где доступно, отдельная выдержка. Запись `unavailable` не означает отсутствия произведения.

`npm audit --omit=dev`: 0 уязвимостей рабочих зависимостей на дату проверки. Полный аудит сообщает предупреждения умеренной важности в цепочке ESLint из-за minimatch <11.0.1 (GHSA-g3hv-75wg-m249). Автоматическая рекомендация npm предлагает несовместимое понижение eslint-config-next; оно не применено. На обработку пользовательских данных работающим сайтом этот инструмент проверки не используется. Перед развитием инструментов разработки стоит проверить совместимое обновление цепочки.

На внешний сервер ничего не выкладывалось. Домен и DNS не настраивались.
