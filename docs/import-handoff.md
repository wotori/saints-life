## Порядок продолжения

1. Прочитать AGENTS.md, docs/architecture.md и docs/content-policy.md. Проверить git status и checkpoint.
2. Читать страницы из ../staints-life-sources/rostovskij-ocr.sqlite3: таблица pages, поля book_number, page, body. Для февраля book_number = 6. Читать ограниченными порциями; обрезанный вывод не считать прочитанным.
3. Проверять текст, примечания, подписи и границы. Не объединять тезок по имени, не выводить святость из сана, родства или исцеления. Сохранять авторство и исторические расхождения как сообщения издания.
4. Перед добавлением карточки проверить существующий каталог. Оригинал OCR не изменять. Не присваивать другим церковным традициям книжную дату автоматически.
5. Обновить данные сайта, отдельный review и checkpoint. Для неполного раздела заполнить activeReview и следующую непрочитанную страницу внутри review.
6. После изменений данных выполнить npm run data:audit-coverage, npm run check, npm run test:e2e. Последняя команда включает npm run build.
7. Проверить diff, сделать тематический коммит и push. Пользователь разрешил промежуточные коммиты и push. Не выкладывать production без отдельного запроса.
8. Записать новую точку продолжения сюда. Не объявлять цель завершенной по числу прочитанных страниц или зеленым тестам.
