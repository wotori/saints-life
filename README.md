# Saints Life

Бесплатный публичный каталог святых и их житий. Цель проекта: постепенно собрать сведения обо всех святых, сохраняя источники, разные версии житий и свидетельства почитания в православных и старообрядческих традициях.

Сейчас это работающий исследовательский прототип на Next.js 16, React 19 и TypeScript. Начальная коллекция посвящена святым с именем Димитрий. Код проекта опубликован в открытом репозитории: https://github.com/wotori/saints-life.

## Запуск

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:3100. Внешние API, база данных и ключи не нужны.

## Что работает

- Главная с первой коллекцией Димитриев.
- Каталог: поиск по имени/месту, варианты Дмитрий/Димитрий, фильтры традиции, лика и наличия чтения, пагинация.
- Карточки 68 записей из именослова «Азбуки веры» и протопопа Аввакума.
- 7 кратких редакционных изложений. Для Солунского также 3 внешних версии: Димитрий Ростовский, Филарет Черниговский, «Русская вера».
- Читалка с автором и описанием издания, источниками, размером шрифта, тёмной темой и локальной закладкой версии.
- Календарь: выбор дня, месяц вперёд/назад, переход к дате, поиск, фильтр традиции, оба календарных стиля и ссылки, сохраняющие выбранный день.
- Реестр 13 используемых источников и страница о границах подборки.

Прототип не выдаёт подборку одного источника за полный общецерковный список. Большинство карточек пока не имеют локального жития. Переходящие памяти перечислены, но не включены в сетку до сверки правил. Нет учётных записей, синхронизации закладок, полного текста защищённых изданий и production-деплоя. Индексация прототипа закрыта через metadata robots.

## Структура

```text
src/app/          страницы App Router и стили
src/components/  каталог, календарь, читалка и навигация
src/domain/      модель предметной области
src/data/        источники, тексты и начальный указатель
src/lib/         чтение данных, поиск, календарные вычисления
scripts/         воспроизводимая сборка указателя и архив источников
tests/           контракты данных/календаря и браузерные сценарии
docs/            архитектура и правила подготовки материалов
../staints-life-sources/  архив оригиналов, выдержек и реестр материалов
```

Подробно: [архитектура](docs/architecture.md), [правила материалов](docs/content-policy.md).

## Проверки

```sh
npm run check
npm run build
npm run test:e2e
```

Браузерные тесты собирают production-версию, используют установленный Google Chrome и отдельный локальный порт 3101. Рабочий dev-сервер на 3100 не переиспользуется. Скриншоты главной, читалки и календаря для desktop и mobile сохраняются в `test-results/`.

## Пополнение

Фактические записи хранятся в `src/data/dimitri-directory.tsv`; `npm run data:build` пересобирает `directory.json`. Нельзя вручную исправлять только сгенерированный JSON.

Произведения, издания, версии для чтения и источники описаны раздельно в `src/data/library.ts`. Связи и правила календаря проверяются тестами. Расширение списка не должно автоматически приписывать почитание другой церкви.

```sh
npm run sources:export
npm run sources:archive
```

Архив расположен рядом с репозиторием. `manifest.json` фиксирует путь, URL, дату скачивания, SHA-256, объём и ошибки. Неудачная загрузка не подменяется пустым документом; выдержки называются выдержками. Архив не участвует в работе публичного сайта.
