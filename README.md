# Saints Life

Бесплатный публичный каталог святых и их житий. Цель проекта: постепенно собрать сведения обо всех святых, сохраняя источники, разные версии житий и свидетельства почитания в православных и старообрядческих традициях.

Сейчас это работающий исследовательский прототип на Next.js 16, React 19 и TypeScript. Начальная коллекция включает святых с именем Димитрий и несколько других святых, связанных с местными книгами. Код проекта опубликован в открытом репозитории: https://github.com/wotori/saints-life.

## Запуск

```sh
npm ci
npm run dev
```

Адрес: http://127.0.0.1:3100. Внешние API и ключи не нужны. Для раздела книг используются локальные базы SQLite в соседнем архиве.

## Что работает

- Главная с первой коллекцией Димитриев.
- Каталог: поиск по имени/месту, варианты Дмитрий/Димитрий, фильтры традиции, лика и наличия чтения, пагинация.
- Карточки святых, включая 68 записей из именослова Димитриев, протопопа Аввакума и святых, связанных с местными книгами.
- 7 кратких редакционных изложений. Для Солунского также 3 внешних версии: Димитрий Ростовский, Филарет Черниговский, «Русская вера».
- Читалка с автором и описанием издания, источниками, размером шрифта, тёмной темой и локальной закладкой версии.
- Календарь: выбор дня, месяц вперёд/назад, переход к дате, поиск, фильтр традиции, оба календарных стиля и ссылки, сохраняющие выбранный день. При выборе всех традиций отдельно показываются предварительные даты из распознанных печатных указателей, со ссылкой на скан и без утверждений о других традициях.
- Реестр используемых источников и страница о границах подборки.

Прототип не выдаёт подборку одного источника за полный общецерковный список. Большинство карточек пока не имеют локального жития. Переходящие памяти перечислены, но не включены в сетку до сверки правил. Нет учётных записей, синхронизации закладок, проверенных прав для публичного распространения современных изданий и production-деплоя. Индексация прототипа закрыта через metadata robots.

## Структура

```text
src/app/          страницы App Router и стили
src/components/  каталог, календарь, читалка и навигация
src/domain/      модель предметной области
src/data/        источники, тексты и начальный указатель
src/lib/         чтение данных, поиск, календарные вычисления
scripts/         воспроизводимая сборка указателя и архив источников
tests/           контракты данных/календаря и браузерные сценарии
docs/            архитектура и правила подготовки материалов
../staints-life-sources/  архив оригиналов, выдержек и реестр материалов
```

Подробно: [архитектура](docs/architecture.md), [правила материалов](docs/content-policy.md).

## Проверки

```sh
npm run check
npm run test:import
npm run build
npm run test:e2e
```

Браузерные тесты собирают production-версию, используют установленный Google Chrome и отдельный локальный порт 3101. Рабочий dev-сервер на 3100 не переиспользуется. Скриншоты главной, читалки и календаря для desktop и mobile сохраняются в `test-results/`.

## Пополнение

Фактические записи хранятся в `src/data/dimitri-directory.tsv`; `npm run data:build` пересобирает `directory.json`. Нельзя вручную исправлять только сгенерированный JSON.

Произведения, издания, версии для чтения и источники описаны раздельно в `src/data/library.ts`. Связи и правила календаря проверяются тестами. Расширение списка не должно автоматически приписывать почитание другой церкви.

```sh
npm run sources:export
npm run sources:archive
```

Архив расположен рядом с репозиторием. `manifest.json` фиксирует путь, URL, дату скачивания, SHA-256, объём и ошибки. Неудачная загрузка не подменяется пустым документом; выдержки называются выдержками. Локальная библиотека использует базы и книги из архива, но сам архив в репозиторий не входит.

Подробная схема происхождения книг, связей и восстановления: [docs/library-provenance.md](docs/library-provenance.md).

## Локальная библиотека книг

Раздел `/library` читает SQLite-базу `../staints-life-sources/library.sqlite3`. Для неё нужен Node.js с `node:sqlite` (проверено на Node 25). Детская книга импортируется из текстового слоя PDF, с указанием страниц оригинала:

```sh
python3 scripts/import-kids-pdf.py
```

Расположение архива можно изменить через `SAINTS_SOURCES_DIR`. Отдельные пути к базам задаются через `SAINTS_LIBRARY_DB`, `SAINTS_OCR_DB` и `SAINTS_INDEX_DB`. Если сохранённый в базе путь к PDF недоступен, скан ищется в архиве по известному имени; контрольная сумма PDF проверяется перед показом, чтобы не подменить издание. Оба ознакомительных EPUB по решению владельца исключены из каталога. Оригиналы книг, их копии и базы находятся вне репозитория.

В архив также включена книга «Владыка Иоанн - святитель русского зарубежья» (четвёртое издание, 2014). Её скан обрабатывается вместе с книгами Ростовского. В разделе `/library/john` доступны 17 сверенных по границам глав жизнеописания и распознанное печатное содержание всего издания. Детская книга содержит 28 произведений, связанных с проверенными карточками святых. У детской книги год и права конкретного издания не подтверждены по выходным данным.

В папке книг обнаружено 12 PDF издания «Жития святых на русском языке, изложенные по руководству Четьих-Миней святого Димитрия Ростовского» (Москва, «Ковчег», 2010). Это новый набор дореволюционного русского издания, а не буквальный текст первоначальных церковнославянских Четьих-Миней. Страницы сканов распознаются локально, результат хранится отдельно в `../staints-life-sources/rostovskij-ocr.sqlite3` и доступен на сайте с указанием книги и номера страницы PDF. Для каждой страницы можно открыть исходный скан; в режиме непрерывного чтения выводится до десяти страниц подряд. Права на набор, оформление и иллюстрации этого издания требуют проверки перед публичным распространением.

```sh
python3 scripts/ocr-books.py --workers 3
```

Нужны локальные `pdfinfo`, `pdftoppm` и Tesseract с русским языком. Обработка возобновляется с последней страницы; команда `--retry-errors` повторяет ошибки. Двойной одновременный запуск блокируется; изменения исходных файлов обнаруживаются по SHA-256. `SAINTS_OCR_DB` задаёт путь к базе для приложения. Промежуточные изображения помещаются в соседний архив и удаляются после распознавания страницы.

Поиск индексирует исходный OCR и дополнительный вариант с объединением слов, перенесённых на следующую строку. Для уже распознанных страниц индекс можно обновить командой `python3 scripts/refresh-ocr-search.py`; флаг `--watch` сопровождает выполняющееся распознавание. В читалке объединение переносов включается отдельно и не меняет исходный текст. Настоящий дефис тоже может быть принят за перенос, поэтому результат следует сверять со сканом.

Оглавление по колонтитулам и поиск строятся по уже распознанным страницам и обновляются по мере обработки. На страницах с найденными заголовками можно открыть предполагаемый раздел до следующего найденного заголовка. Длинный раздел показывается частями по 40 страниц: продолжение остаётся в пределах автоматически найденной границы. Границы и текст могут содержать ошибки; у каждой страницы есть ссылка на скан. Заголовки не являются проверенным списком персоналий. Списка всех святых в базе пока нет. Распознанные страницы автоматически не приписываются отдельным святым без проверки.

Печатные алфавитные указатели томов распознаются отдельной возобновляемой командой `python3 scripts/ocr-book-indexes.py --workers 2`. Нужен установленный локально Pillow. Результат находится в `../staints-life-sources/book-indexes.sqlite3` и доступен для поиска по имени; исходную строку необходимо сверять со сканом. Для некоторых строк сайт предлагает приблизительную страницу книги, если номер и смещение страниц удалось определить автоматически. Путь к этой базе можно задать через `SAINTS_INDEX_DB`.

На странице строки указателя можно искать имя в тексте выбранного тома или ввести номер печатной страницы со скана. Переход к странице PDF доступен, когда смещение нумерации подтверждается достаточным числом распознанных колонтитулов; полученную страницу всё равно следует сверить со сканом.

Дополнительный проход `python3 scripts/ocr-index-numbers.py` локально распознаёт числовые колонки отдельно. Скрипт сверяет контрольные суммы книг, расположение строк и уже читаемые числовые ссылки; сомнительные колонки пропускаются. Результаты хранятся отдельно от исходного OCR и ручных правок и показываются как предварительные. Можно обработать отдельную страницу с `--book 2 --page 623`. Нужны Tesseract с русским и английским языками, Poppler и Pillow.

Команда `npm run data:book-index` сохраняет отдельные строки указателей в той же базе вместе с исходным OCR, контрольной суммой книги и статусом проверки. Повторная сборка не перезаписывает проверенные записи: если их источник изменился, она завершится с ошибкой для ручной сверки. Эти строки остаются предварительными, пока их не проверили по оригиналу.

Для сверки строк со сканом используется `npm run data:review-index -- путь-к-json`. Пример подготовленной проверки хранится в архиве источников в `reviews/rostovskij-01-p669-left.json`. Команда проверяет отпечаток исходной строки и книги, сохраняет исходное распознавание и журнал изменений; вся группа откатывается при ошибке. Сверка строки не означает, что установлена личность святого или проверено всё житие.

Если строка OCR не попала в каталог, её можно зарегистрировать для последующей сверки командой `npm run data:register-index-lines -- путь-к-json`. Каждая ссылка содержит книгу, страницу, номер строки и отпечаток исходного OCR вместе с контрольной суммой книги. При изменении исходной строки повторная сборка прерывается, чтобы не перезаписать редакторскую проверку. Пример находится в архиве источников: `reviews/rostovskij-01-p671-supplement.json`.

Строки, которые после сверки со сканом оказались артефактами OCR, можно скрыть командой `npm run data:exclude-index-lines -- путь-к-json`. Исходный текст, причина и журнал решения сохраняются; повторная сборка не возвращает такие строки в поиск.
